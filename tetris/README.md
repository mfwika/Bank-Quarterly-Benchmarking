# Block Drop

An offline, Tetris-style game in one HTML file with no dependencies.

**Play:** download `index.html` and double-click it. It runs in any modern browser with no internet connection.

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | ← → (or A / D) | ◀ ▶ buttons, or drag on the board |
| Soft drop | ↓ (or S) | ▼ |
| Hard drop | Space | DROP, or swipe down |
| Rotate | ↑ / X (Z rotates back) | ⟳ ⟲, or tap the board |
| Hold | C / Shift | HOLD, or swipe up |
| Pause | P / Esc | PAUSE |
| Sound on/off | M | in the pause menu |

Your best score is saved in the browser.
